# DMT — DayZ Minimal UI Test

Чистый контрольный мод для проверки GUI и клиент-серверной синхронизации на DayZ 1.30.

## Цель

- Независимый текстовый HUD справа сверху с серверным временем `HH:MM:SS`.
- Раз в секунду сервер отправляет клиенту авторитетные дату/время.
- При открытом инвентаре отображается дата `DD.MM.YYYY` второй строкой.
- Подробная компактная диагностика в `script.log` и сообщениях чата.
- Создание одного корневого виджета из одного `.layout`; никаких кастомных инвентарных меню и обхода UI lifecycle.

## Структура

- `config.cpp` — регистрация модулей.
- `Scripts/5_Mission/dmt_cln.c` — клиентский HUD, обработка RPC и обнаружение инвентаря.
- `Scripts/5_Mission/dmt_srv.c` — серверные часы и отправка RPC.
- `GUI/dmt.layout` — один текстовый виджет.

## Тест

1. Собрать PBO с префиксом `dmt`.
2. Подключить мод одновременно к серверу и клиенту.
3. В `script.log` клиента проверить последовательность `dmt_cln:...` и в логе сервера — `dmt_srv:...`.
4. Убедиться, что часы идут, дата появляется/исчезает при открытии/закрытии инвентаря и интерфейс не дублируется после повторного открытия.
5. Повторить после полного перезапуска клиента и на dedicated-сервере.

Требуется внутриигровая проверка: доступ к репозиторию сам по себе не позволяет запустить DayZ/Enforce Script compiler.

## Формат лога

`[DMT][dmt_cln:NN] STEP/STATE key=value`

Номер передаётся как константа вызова и должен обновляться после изменения строк в файле. Чат показывает короткие одноразовые переходы, а не каждый кадр.
