# DayZ Minimal Interface Test

Чистый контрольный мод для проверки создания интерфейсов и связи между клиентом и сервером в DayZ 1.30.

## Назначение

- Независимый текстовый интерфейс в правом верхнем углу с текущим системным временем серверной машины в формате `HH:MM:SS`.
- Сервер отправляет дату и время клиенту раз в секунду через сетевой вызов.
- При открытом инвентаре под временем отображается дата в формате `DD.MM.YYYY`.
- Подробная диагностика записывается в `script.log` и кратко выводится в игровой чат.
- Используется один корневой элемент интерфейса из одного файла разметки. Собственное меню инвентаря не создаётся.

## Структура

- `config.cpp` — регистрация мода и его скриптов.
- `Scripts/5_Mission/dmt_cln.c` — клиентский интерфейс, обработка сетевых сообщений и отслеживание состояния инвентаря.
- `Scripts/5_Mission/dmt_srv.c` — серверные часы и отправка времени клиентам.
- `GUI/dmt.layout` — разметка одного текстового элемента.
- `$PBOPREFIX$.txt` — путь корня упакованного мода.

## Проверка в игре

1. Собери архив мода.
2. Подключи мод одновременно на сервере и клиенте.
3. В клиентском `script.log` проверь сообщения с именем `dmt_cln`, а в серверном — сообщения с именем `dmt_srv`.
4. Убедись, что время меняется каждую секунду, дата появляется и исчезает вместе с инвентарём, а после повторного открытия интерфейс не дублируется.
5. Повтори проверку после полного перезапуска клиента и на выделенном сервере.

Это прототип. Компилятор Enforce Script и сама DayZ в этой сессии не запускались, поэтому успешная компиляция и отрисовка пока не подтверждены.

## Формат диагностики

`[DayZ Minimal Interface][dmt_cln:номер_строки] полное описание события`

В записи указан файл и номер строки, где произошло событие. Игровой чат показывает понятные сообщения о запуске, ошибках и смене состояния, а не сообщения при каждом обновлении кадра.
